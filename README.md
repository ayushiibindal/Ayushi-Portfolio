# Ayushi Bindal Portfolio Website

A modern and responsive personal portfolio website built using HTML, CSS, and JavaScript to showcase my skills, projects, experience, certifications, and achievements as a Computer Science Engineering student. 

## ✨ Features

* Fully responsive modern UI
* Smooth scrolling and animations
* Interactive particle background
* Custom animated cursor
* Dynamic typing effect
* Project filtering system
* Skill progress bars
* Timeline-based experience section
* AI-powered contact form reply
* Mobile-friendly navigation menu

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (Vanilla JS)
* Figma (for UI/UX concepts)
* Google Fonts
